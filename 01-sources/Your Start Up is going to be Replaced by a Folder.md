# Your Start Up is going to be Replaced by a Folder

You don't need hundreds of agents; you need a good library and one good librarian.

## Key points
- Most second brains are numbered folders of markdown: decisions, processes, projects.
- Short router notes tell the model where to look, like a card catalog.
- At company scale you add access control, governance and monitoring.
