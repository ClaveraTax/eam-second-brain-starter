# Stop Buying Agent Tools. Your Folders Already Do This

**In one line:** a sub-agent is one model reading instructions in a separate chat, and a well-organised folder already *is* those instructions.

## Key claims
- Pointing an assistant at a folder, instead of re-explaining the task each time, saves most of the instruction tokens (he cites ~97%).
- "Agent" is a name we give to automations so we can keep track of them. It's a user-experience label, not a new technology.
- Providers will converge on roughly the same agent harness, the way browsers converged on Chromium. Don't build orchestration; invest in your own judgement, descriptions and structure.
- Parallel sub-agents buy speed, not savings. They burn more tokens.
- Design **stages and stopping points** into the folder structure so you decide where the AI pauses for review: augment, not just automate.

## My take
The "stages with gates" idea is the one to steal for governance-heavy work: the review step lives in the structure, not in a separate approval tool. The 97% figure is his claim, not a measurement I've checked.

Arguing against buying an "agent platform" before the team's knowledge is organised. See `02-people/Example — Group CISO.md`.
