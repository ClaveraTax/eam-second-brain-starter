Five open-source tools that can stand in for paid AI subscriptions, if you run your own server.

## Key points

- Ollama runs open models on your own hardware.
- Dify builds AI workflows visually, and OpenHands is a coding agent you host yourself. A router and a compression layer cut token costs on top.
