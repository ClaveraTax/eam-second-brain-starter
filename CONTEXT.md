# CONTEXT: start here

This file tells you (and your assistant) where things live. Load only the folder a task needs.

| Folder | Holds |
|---|---|
| `00-inbox/` | Stage 1. Raw drops: pasted text, quick thoughts. Temporary. |
| `01-sources/` | Stage 2. One short note per video, article or document. |
| `02-people/` | Stage 2. One note per person you learn from: how they think. |
| `03-briefs/` | Stage 3. Things you use: meeting prep, memos, one-pagers. |
| `skills/` | Reusable prompts: capture a source, write a person note, weekly review. |

**Stopping points:** the assistant drafts; you approve before anything is saved, moved or deleted.
