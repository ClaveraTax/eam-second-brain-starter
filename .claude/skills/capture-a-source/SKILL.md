# Capture a source

Turn the material the user gives you into a short source note.

1. Only what the source says. Three key points at most.
2. Leave "My take" as a question for the user.
3. Link the author's note (`02-people/` or `02-businesses/`) and one or two notes in `02-concepts/`. If one doesn't exist, say so instead of creating it.
4. Use the format in `01-sources/_template.md`, file name on the first line: `→ save as 01-sources/<Title>.md`
5. Stop and wait for the user's edits before saving.
