# Capture a source

> [!TIP]
> **Not using Claude Code?**
>
> Paste this file into your assistant, then paste your material.

Turn what the user gives you into a short source note.

1. Write only what the source says, in three key points at most.
2. Leave "Your take" as a question for the user.
3. Link the author's note (`02-people/` or `02-businesses/`) and one or two notes in `02-concepts/`. If a note doesn't exist yet, say so rather than inventing one.
4. Follow `01-sources/_template.md` and put the file name on the first line: `→ save as 01-sources/<Title>.md`
5. Stop there and wait for the user's edits.
