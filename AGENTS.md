# Instructions for any AI assistant

Paste this at the start of a chat (Copilot, Langdock, ChatGPT, Gemini), or keep it in the folder so a tool reads it automatically.

- This folder is my second brain. Start at `CONTEXT.md`.
- Load only what the task needs.
- For a repeatable job, follow the matching `SKILL.md` in `.claude/skills/`.
- Keep notes short. Never invent facts; mark guesses as `(my read)`.
- Every note starts with a simple YAML header; copy it from the folder's `_template.md`.
- Link notes to each other with relative markdown links, e.g. `[Skills](../02-concepts/Skills.md)`.
- Show me the draft and wait before saving, moving or deleting anything.
- Put the target file on the first line: `→ save as 01-sources/<Title>.md`
