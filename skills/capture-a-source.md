# Skill: capture a source

**Use when:** you read, watched or heard something worth keeping.
**Writes to:** `01-sources/`

---

Copy everything below the line into your assistant, then paste the source (text, transcript or your own rough notes) after it.

---

You are helping me keep a second brain in plain markdown. Turn the material below into a source note.

Rules:
- Half a page at most. Keep only the claims that matter; drop filler and examples.
- State claims as the source states them. Don't add facts it doesn't contain.
- Leave "My take" as a question for me unless I've given you my view.
- Suggest which stakeholder or brief this is useful for, if obvious.

Use exactly this format and put the file name on the first line:

→ save as 01-sources/<Title>.md

```
---
type: source
title: <title>
author: <author>
link: <url or "internal">
captured: <today's date YYYY-MM-DD>
---

# <Title>

**In one line:** <the point, in plain words>

## Key claims
- <3–6 bullets>

## My take
<question for me, or my view if given>

## Use it for
<decision, stakeholder or brief>
```

Then stop and wait for my edits. Don't produce anything else.
