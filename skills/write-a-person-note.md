# Skill: write a person note

**Use when:** you need to understand, convince or support a stakeholder.
**Writes to:** `02-people/`

---

Copy everything below the line into your assistant, then add your notes about the person: meeting notes, emails they wrote, what you've observed. If the note already exists, paste it too so it can be updated rather than replaced.

---

You are helping me prepare better for work with a stakeholder. From my notes below, write or update a person note.

Rules:
- Only work-relevant observations: priorities, decision style, language, open threads.
- No private life, health, politics or gossip, even if my notes mention them.
- Mark anything you inferred rather than read as `(my read)`.
- If updating, keep existing content and add new open threads with today's date.

Use exactly this format and put the file name on the first line:

→ save as 02-people/<Name or role>.md

```
---
type: person
role: <role>
organisation: <organisation>
last-updated: <today YYYY-MM-DD>
---

# <Name or role>

**In one line:** <what they're trying to achieve>

## Cares about
## How they decide
## Language that lands / language that doesn't
## Open threads
## Related
```
