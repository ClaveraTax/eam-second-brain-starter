# Tools I use

What I use for my own second brain, roughly in the order of the four phases.

- [Folders + Markdown](../CONTEXT.md): plain files you own
- [Langdock](https://www.langdock.com): AI assistant on EU endpoints
- [Hermes Agent](https://github.com/NousResearch/hermes-agent): keeps the brain curated
- [Telegram](https://telegram.org): ask it from your phone
- [Obsidian](https://obsidian.md): see the connections
- [Graphify](https://github.com/Graphify-Labs/graphify): knowledge graphs for AI
- [Paperclip](https://paperclip.ing): run a team of agents

> [!NOTE]
> **Honourable mention**
>
> [BMAD Method](https://github.com/bmad-code-org/BMAD-METHOD)

> [!CAUTION]
> **Start with the first two**
>
> Folders and an approved assistant need no install. Everything after that does, so check with IT before trying it on a work laptop.
