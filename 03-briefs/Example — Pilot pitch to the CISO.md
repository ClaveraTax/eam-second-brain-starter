# Example — Pilot pitch to the CISO

> Fictional example. Built from the CISO person note and one source note.

**Ask:** approve a 6-week pilot for 5 architects using our already-approved assistant and one SharePoint folder.

**Why it's low risk** (their language):
- Stays in our tenant. No new vendor, no plugin.
- Plain markdown files we already govern, with the usual retention and access rights.
- Every AI draft is reviewed by a human before it's saved (stage gates).

**What I'll bring:** a one-page data-flow drawing and the folder structure (`CONTEXT.md`).

**What success looks like:** each architect's meeting prep time is halved, measured by a before/after self-report.
